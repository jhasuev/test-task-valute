# Currency Converter

Приложение для конвертации валют с поддержкой USD, EUR и RUB.

## Функционал

- Отображение курсов валют относительно выбранной основной валюты
- Конвертация между любыми поддерживаемыми валютами
- Автоматическое обновление курсов каждую минуту
- Валидация пользовательского ввода
- Адаптивный дизайн

## Технологии

- Vue 3 + TypeScript
- Vue Router для навигации
- Pinia для управления состоянием
- Vuelidate для валидации форм
- SCSS для стилизации
- Feature-Sliced Design для архитектуры

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите проект в режиме разработки:
```bash
npm run dev
```

4. Для сборки проекта:
```bash
npm run build
```

## Структура проекта

```
src/
  ├── app/              # Инициализация приложения
  ├── processes/        # Процессы приложения
  ├── widgets/          # Композиционные компоненты
  ├── features/         # Функциональные модули
  ├── entities/         # Бизнес-сущности
  └── shared/          # Переиспользуемый код
```

## API

Приложение использует API `https://status.neuralgeneration.com/api/currency` для получения курсов валют.
